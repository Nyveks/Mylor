# Mylor ❤️‍🔥

**Mylor** is an agentic AI assistant with a real, dedicated Linux environment behind it — not a sandbox that disappears when the chat ends. It can reach into your laptop, your server, or any device you connect, and actually get things done there: running commands, managing files, executing code, and carrying out multi-step tasks the way a capable human assistant would if you handed them the keyboard.

Most AI assistants can only talk about a task. Mylor can go do it.

## What makes Mylor different

- **A real operating system, not a simulation.** Every session runs on an actual Linux environment, so Mylor can install packages, run scripts, manage files, and interact with a real filesystem — not a stripped-down sandbox with fake capabilities.
- **Reaches your own devices.** Connect your laptop or another machine, and Mylor can operate on it directly — moving files, running processes, checking on things, or fixing them, wherever you point it.
- **Built to finish tasks, not just describe them.** Mylor plans, executes, checks its own work, and adapts when something doesn't go as expected — the way an agent should.
- **A ready-to-use app.** Mylor isn't a framework or a developer toolkit you have to wire together yourself. Install it, connect your device, and start giving it real work.

## Who it's for

If you've ever wished you could just tell your computer what you need done instead of doing it yourself — Mylor is built for that. No coding background required, no configuration maze. It's an assistant for anyone who wants an AI that can actually touch their machine and get real work done, not just chat about it.
